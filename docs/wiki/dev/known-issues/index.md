# Known Issues

Known issues and limits of the Chart Internals guides. Create a page when there is an issue to
record, using the same file name as its internals guide. Name it in that guide's Known Issues section.

Use these sections when they have entries:

- **Need Verification**: reported or suspected, but not reproduced yet.
- **Confirmed**: reproduced by a test, a screenshot, a rendered chart, or the code. Each entry says
  how.

Move an issue to Confirmed once something reproduces it, and delete it once it is fixed. When the
last issue is resolved, remove the issue page and its guide's reference.
